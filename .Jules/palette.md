## 2025-05-22 - Mermaid Accessibility and Visual Hierarchy
**Learning:** Mermaid diagrams in Markdown can be significantly improved for accessibility using `accTitle` and `accDescr`. For security-focused workflows, a semantic `security` class (`fill:#f96,stroke:#333,stroke-width:2px`) combined with subtle subgraph background colors (`fill:#e8f5e9`, etc.) improves scannability and highlights the DevSecOps integrations.
**Action:** Always include accessibility metadata and semantic color-coding when creating or modifying Mermaid diagrams in documentation.
