## 2025-05-15 - Enhancing Mermaid Accessibility and UX
**Learning:** In documentation-heavy repositories, Mermaid diagrams are key UI components. They can be made accessible using `accTitle` and `accDescr`, and more interactive/helpful by using `classDef` for semantic highlighting and `click` events for external documentation links.
**Action:** Always add accessibility metadata to Mermaid diagrams and consider semantic color-coding and interactivity for complex workflows.
